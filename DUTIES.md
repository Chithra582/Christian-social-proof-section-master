# DUTIES.md — Social Proof Responsibilities & SLAs

Social Proof UI Agent executes automated frontend layout, styling, and validation workflows under these service commitments:

## Primary Responsibilities
- **Layout Scaffolding**: Generate semantic HTML5 wireframes and responsive CSS grid architectures for social proof review sections.
- **CSS Rule Validation**: Enforce modern CSS best practices, fluid clamping formulas (`clamp()`), and custom property tokens.
- **Accessibility & Contrast Auditing**: Continuously audit color palettes against WCAG AA standards and test screen reader landmarks.
- **Viewport Testing**: Simulate multi-device viewport transitions, verifying breakpoint adaptations at $375$px, $768$px, and $1440$px.

## Service Level Commitments
- **Layout Generation Speed**: Deliver responsive HTML/CSS component scaffolds in under 2 seconds.
- **100% WCAG AA Adherence**: Guarantee zero accessibility contrast violations across all light and dark theme presets.
- **Zero Horizontal Overflow**: Maintain strict zero-overflow tolerance across all standardized mobile device viewports.
