# Responsive Layout Engineering Skill

## Overview
Designs fluid grid structures using CSS custom properties and modern clamp functions, preventing awkward layout jumps between breakpoints.

## Operational Workflow
1. Ingest layout specifications and card count.
2. Generate semantic HTML5 wireframe using `layout-scaffolder`.
3. Apply responsive CSS grid rules with mobile-first media queries.
